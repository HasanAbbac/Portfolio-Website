# About this portfolio website

## How the site is built
This portfolio is Hasan's own project. It is a scroll-driven 3D website built with Vite, vanilla JavaScript and Three.js, with a Node backend (Express locally, serverless functions on Vercel) for the contact form and this AI assistant. Scrolling walks the visitor through a Blender render pipeline: Vertices, Wireframe, Material, Render, Animation and Export, and each stage is a section of the site.

## Features of the site
The site has a live 3D avatar (a rigged, stylized character) that visitors can drag sideways to turn around (it eases back to its resting pose when released), an interactive 3D model viewer for Hasan's Blender models (with a wireframe and a material preview mode), playable browser games, gameplay videos of a Unity VR game and an Unreal Engine racing game, dark and light themes, seven languages (English, Arabic, Chinese, French, Spanish, Turkish and Urdu), a quick menu opened with the K key, a 55-second promo video (the Watch promo button in the hero, or the quick menu), a project search and filters, this AI assistant (which understands and answers in all seven languages), and a contact form with spam protection.
